# Quick Reference Card: Template Updates in 3 Steps

**Print this or bookmark it for fast reference**

---

## 🎯 In 3 Steps

### Step 1: Edit
```
1. Open VS Code
2. Open folder: D:\COPilot Workspaces\COPilot_Template
3. Click file you want to change
4. Edit text
5. Press Ctrl+S to save
```

### Step 2: Upload
```
1. Press Ctrl+Shift+B
2. Select: "Template: Full Update Workflow"
3. Type what you changed (e.g., "Add new best practices")
4. Press Enter
5. Wait for ✓ checkmark
```

### Step 3: Done ✓
```
Changes are now on GitHub
All workspaces will get updates
```
